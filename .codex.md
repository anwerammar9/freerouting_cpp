# Codex Instructions — Freerouting C++ Migration

## Project
Migrating Freerouting PCB autorouter from Java to C++20. Java source is truth.
Goal: headless routing parity (load DSN → route → write SES).

## First Steps
1. Read `SOURCE_OF_TRUTH/README.md` for status
2. Read `SOURCE_OF_TRUTH/01_MEMORY.md` for architecture and conventions
3. Read `SOURCE_OF_TRUTH/05_WORK_PACKAGES.md` for current tasks

## Build
```bash
cmake --build build --target <module_target> -j$(nproc)
ctest --test-dir build --output-on-failure
```

## Rules
- Java files in `java/app/freerouting/**` are the reference — port faithfully
- Each class needs 3 files: `.h`, `.cpp`, `_test.cpp`
- Use C++20: smart pointers, RAII, `std::optional`, `#pragma once`
- Naming: PascalCase classes, snake_case functions, trailing `_` for private members
- `freerouting_core` is a leaf library — no dependencies
- Never include `src/board/Components.h/.cpp` — it's dead code
- Java nets are 1-based — adjust for 0-based C++ indexing
- Both `ctest` and `run_tests` must pass

## After Making Changes
1. Build the affected module
2. Run tests
3. Update `SOURCE_OF_TRUTH/02_PROGRESS.md` with completed work
4. Update `docs/migration/INDEX.md` with new percentages
